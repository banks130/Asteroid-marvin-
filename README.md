# Asteroid Marvin – Landing Page

A modern, responsive single‑page landing site for the **Asteroid Marvin** memecoin, built with HTML, CSS, and vanilla JavaScript. The design uses a space‑themed aesthetic and is optimized for mobile to help users easily share and grow the community.

## 🌌 Features

- Space‑themed, dark background with stars and nebulas for a cosmic feel.  
- Hero section with Marvin in an asteroid‑style spacesuit (image placeholder in `index.html`).  
- Project narrative section explaining the Asteroid Marvin story and community.  
- **“Copy Address”** button that copies the token address  
  `0x758b2f798458612d91105e633bd1bc4793de4444` to the clipboard.  
- Links to the project’s official X (Twitter) and Telegram channels.  
- CTA button that opens the **Four.meme token page** for buying/selling.  
- Fully responsive layout (mobile‑first) for easy sharing on phones and tablets.
